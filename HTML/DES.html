3. DESIGN
3.1 SYSTEM ARCHITECTURE

The architecture of the Exoplanet Data Analysis and Visualization System follows a multi-tier pipeline model that links external data repositories, a local database management system, and an interactive data exploration interface. The workflow is structured into four core layers:

  • Data Source Layer: Retrieves raw tabular astrophysical datasets via REST API endpoints from the NASA Exoplanet Archive and stores them locally as comma-separated values (CSV).
  • Preprocessing & Ingestion Layer: Utilizes Python's Pandas library to handle missing records (filling null entries with 'Unknown') and maps the DataFrame structure directly into a relational MySQL database (Analysis database, PlanetData table) via SQLAlchemy.
  • Query & Processing Layer: Interactively prompts the user to select specific X and Y astrophysical parameters. Executes parameterized SQL queries that filter out incomplete records (WHERE X != 'Unknown' AND Y != 'Unknown') to maintain statistical accuracy.
  • Visualization Layer: Leverages Matplotlib to render log-scale scatter plots, translating raw numerical databases into intuitive visual graphs that reveal cosmic trends and outliers.
3.2 DATABASE SCHEMA & ATTRIBUTE SPECIFICATIONS

The relational database table PlanetData stores a comprehensive multi-parameter astrophysical dataset ingested from the NASA Exoplanet Archive. To maintain data integrity and support complex exploratory data analysis (EDA), the schema is structured into distinct functional categories of attributes:

  • Planetary Characteristics: Attributes defining physical and orbital traits of the exoplanet, including orbital period (pl_orbper), semi-major axis (pl_orbsmax), radius in Earth/Jupiter units (pl_rade, pl_radj), mass equivalents (pl_bmasse, pl_bmassj), orbital eccentricity (pl_orbeccen), equilibrium temperature (pl_eqt), and insolation flux (pl_insol).
  • Stellar Parameters: Attributes characterizing the parent host star, such as effective surface temperature (st_teff), radius (st_rad), mass (st_mass), metallicity (st_met), and surface gravity log(g) (st_logg).
  • Discovery & System Metadata: Identifiers and contextual metadata recording the planet name (pl_name), host star name (hostname), discovery methodology (discoverymethod), discovery year (disc_year), planet count (sy_pnum), stellar count (sy_snum), system distance (sy_dist), and visual magnitude (sy_vmag).
