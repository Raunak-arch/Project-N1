1. INTRODUCTION

In recent years, modern astronomy has entered a data-driven era, with space agencies discovering thousands of planets orbiting distant stars (exoplanets). Managing, storing, and analyzing these massive datasets requires efficient database management systems and powerful programming tools. Plotting graph, furthermore visually allows one to see the deviations from expected trends, which ultimately is responsible for discovery of hidden factors in Astronomy. This project bridges Python programming with a MySQL relational database (Analysis database). Using libraries such as Pandas for data manipulation, SQLAlchemy/PyMySQL for Python-SQL connectivity, and Matplotlib for graphical visualization, this application allows users to interactively analyze relationships between various stellar and planetary characteristics—such as orbital periods (pl_orbper), planetary masses (pl_bmasse), radii (pl_rade), and stellar temperatures (st_teff).

1.1 AIM

To perform exploratory data analysis (EDA) on exoplanet datasets by integrating Python with a MySQL database (Analysis / PlanetData), enabling the extraction, processing, and statistical visualization of astrophysical trends, anomalies, and population distributions while omitting incomplete records (WHERE X != 'Unknown').

1.2 OBJECTIVES
  • Data Acquisition and Preprocessing: To download structural exoplanet datasets from the NASA Exoplanet Archive and utilize Pandas to clean, handle missing values (filling null entries with 'Unknown'), and prepare the dataset for database insertion.
  • Relational Database Creation: To establish a structured MySQL database named Analysis and configure a dedicated table (PlanetData) to persistently store large-scale astrophysical records.
  • Python-SQL Connectivity: To implement a robust backend connection between the Python environment and the local MySQL server using SQLAlchemy and PyMySQL for seamless data storage and retrieval.
  • Exploratory Data Analysis (EDA) & Dynamic Querying: To execute custom SQL queries that filter out incomplete data (WHERE X != 'Unknown' AND Y != 'Unknown') and fetch specific user-defined variables for comparative analysis.
  • Scientific Data Visualization: To generate log-scale scatter plots using Matplotlib, enabling the visual identification of astrophysical trends, correlations, and cosmic anomalies (such as the Neptunian Desert and ultra-low-density planets).
