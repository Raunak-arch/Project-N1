4.2 DATA INGESTION & PIPELINE SETUP

The following Python source code handles loading the dataset via Pandas, managing missing attributes, establishing database connectivity, and populating the MySQL table:

python 

# Importing the Libraries
import pandas as pd
import pymysql
import sqlalchemy
from sqlalchemy import create_engine
import matplotlib.pyplot as plt

# Importing csv in PANDAS for creating DataFrame and handle missing records 
df = pd.read_csv(r"C:/Users/Username/Downloads/data.csv")
df = df.fillna('Unknown')

# Connecting with MySQL using SQLAlchemy/PyMySQL that provides Python-SQL connectivity
engine = create_engine(f"mysql+pymysql://root:12345@localhost:3306/analysis")
df.to_sql('PlanetData', engine, if_exists='append', index=False)
print(df.notnull().sum())# Quick check for getting valid parameters
4.3 INTERACTIVE VISUALIZATION

The interactive loop prompts the user for X and Y coordinate parameters, queries the relational table while filtering out incomplete records, and produces logarithmic scatter plots using Matplotlib:

python 
# Query database and generate scatter plot
X = input('x-parameter:')
Y = input('y-parameter:')
print('fetching database')

# Query filtering out 'Unknown' values to ensure mathematical integrity
df1 = pd.read_sql_query(f"Select `{X}`,`{Y}` From PlanetData WHERE {X}!='Unknown' AND {Y}!='Unknown'", engine)
df1 = df1.astype(float)
df1.plot(x=X, y=Y, kind='scatter')
plt.xscale('log')
plt.yscale('log')
plt.show()
